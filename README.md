# Zangar Kablanbay — Personal Link Page

A responsive personal link page built as a digital visit card. It brings together my social profiles, training links, selected photos, and contact information in one place.

## Live website

[zanggar-link.vercel.app](https://zanggar-link.vercel.app)

## Features

- Responsive, mobile-first layout
- Personal social and contact links
- Animated scrapbook-inspired interface
- Accessible semantic HTML
- Lightweight static build with no runtime dependencies
- Ready for deployment on Vercel

## Built with

- HTML5
- CSS3
- JavaScript
- Node.js build script
- Vercel

## Run locally

```bash
npm run build
npx serve dist
```
